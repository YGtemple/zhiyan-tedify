# 智言：用户调研采集稿

> 用途：收集真实用户需求，支持计划书中的问题定义、场景选择和原型迭代。
> **不要预填答案，不要把意向数据写成实际效果。**

---

## 一、问卷说明

**标题**：大学生口头表达与演示训练需求调研

**开场说明**：本问卷用于大学生表达训练产品的需求研究，采用匿名方式，预计 2-3 分钟完成。结果仅用于创新创业项目研究与产品设计。

**目标样本**：本校本科生为主，覆盖低年级、高年级和不同专业。建议先完成 30 份，再根据结果决定是否扩展到 50-80 份。

## 二、问卷题目

1. 你的年级：大一 / 大二 / 大三 / 大四 / 其他
2. 你的专业类别：文科 / 理工科 / 经管类 / 艺术类 / 医学类 / 其他
3. 近一年你参加过哪些表达场景？（可多选）课堂展示 / 社团或班级汇报 / 竞赛路演 / 求职面试 / 英语演讲 / 尚未参加
4. 你在表达前最担心什么？（可多选）结构不清 / 重点不突出 / 语速和停顿 / 口头禅或重复 / 紧张忘词 / 语言表达不准确 / 不知道如何自我改进 / 其他
5. 你通常如何准备一次展示？（可多选）独自反复练习 / 请同学点评 / 录音或录像复盘 / 依赖教师点评 / 使用 AI 工具 / 很少准备 / 其他
6. 你是否获得过针对「表达过程」的具体反馈？没有 / 偶尔有 / 经常有
7. 如果有工具能在本地对你的表达进行结构化诊断，你最希望得到哪些结果？（可多选）表达结构 / 逻辑衔接 / 语速停顿 / 内容重点 / 语言准确性 / 可执行训练任务 / 训练前后对比
8. 你愿意使用哪种形式的训练？短任务（5-10 分钟）/ 完整模拟（10-20 分钟）/ 文稿自查 / 音频或视频复盘 / 同伴互评辅助
9. 对一次完整的训练反馈，你能接受的等待时间：即时 / 1 分钟内 / 5 分钟内 / 无所谓
10. 你对上传表达材料到在线平台的顾虑有哪些？（可多选）隐私 / 数据保存时间 / 反馈不准确 / 操作复杂 / 没有顾虑 / 其他
11. 你愿意在课程、竞赛或求职准备中试用这类工具吗？愿意 / 需要看到示例后再决定 / 不愿意
12. 请写下你最希望改进的一项表达能力：__________

## 三、半结构化访谈提纲

每次 10-15 分钟，建议访谈 5-8 人。
**记录「原话、具体事件、现有替代方案」，不要只记录态度判断。**

1. 最近一次让你感到表达困难的场景是什么？当时发生了什么？
2. 你如何判断自己表达得好不好？谁给过你反馈？
3. 哪类反馈最有用，哪类反馈最没有用？为什么？
4. 你是否尝试过录音、录像、AI 或同伴点评？实际使用中哪里卡住？
5. 如果只能保留一个功能，你希望它解决哪一个问题？
6. 什么情况会让你愿意连续使用四周？什么情况会让你立刻放弃？
7. 你对上传音频、视频或文字材料有什么隐私要求？

## 这份采集稿的设计要点

### ① 开头就写「不要预填答案」

> 不要预填答案，不要把意向数据写成实际效果。

调研工具最常见的问题是**先有结论再设计问题**。
把这句话写在开头，是给执行者的硬约束。

### ② 问卷题目与产品假设一一对应

| 题目 | 验证什么 |
|---|---|
| 第 4 题 | 「问题缺少结构化诊断」这个痛点真实存在 |
| 第 6 题 | 现有反馈确实不足 |
| 第 7 题 | 用户想要的是哪些诊断维度 |
| 第 8 题 | 训练形式偏好（决定 MVP 用短任务还是完整模拟） |
| 第 10 题 | 隐私顾虑的分布（决定「本地分析」是不是真卖点） |
| 第 11 题 | 试用意愿 |

第 10 题尤其关键——如果多数人选「没有顾虑」，
那「本地分析不上传」这个设计卖点就要重新论证。

### ③ 访谈要求记录「原话、具体事件、现有替代方案」

明确写了：

> 不要只记录态度判断。

「我觉得挺好的」是态度判断，
「我上次在社团汇报时忘了讲成本那部分，
下来同学跟我说没听懂」是具体事件。
前者不能支撑产品决策，后者可以。

### ④ 访谈第 5、6 题是功能优先级探针

- 「如果只能保留一个功能，你希望它解决哪一个问题？」
- 「什么情况会让你愿意连续使用四周？什么情况会让你立刻放弃？」

这两个问题用来排 MVP 功能优先级和
识别流失风险，比问「你想要什么功能」
有效得多。

### ⑤ 结果整理模板把「待采集」写成字

整理表里所有指标都是「待采集」，
不留预填空间。采集完才能填真实结果。
